# Personal Expense Tracker

A C++ console mini project to record expenses, categorize spending
and generate monthly summaries.

## Features
- Add, view and delete expenses
- Custom spending categories
- Monthly summary and yearly overview reports
- Data saved to a file between runs

## OOP Concepts Used
- Classes & Objects (Expense, Category, User, Report)
- Encapsulation (private data members with getters/setters)

## How to Run
g++ -std=c++11 expense_tracker.cpp -o expense_tracker
./expense_tracker
